Use the check in your own app

Pharmacies, clinics, caregiver apps, and researchers can run the same heat and medicine check this site runs. It is the exact code the 300-medicine evidence was measured on.

Why there is no API key

Heat Meds has no server. The check runs in the browser of whoever uses it, and calls only public government services: the National Library of Medicine's RxNorm and the National Weather Service HeatRisk forecast. So there is no key to sign up for, nothing for us to bill or limit, and no medicine list is ever sent to us. A key would need a server that sees people's medicines, which is exactly what this project promises not to do.

Try it with your own data

Paste any list, from a pharmacy printout or a test file. Brand names, doses, and misspellings are fine. You get the same answer the plan page gives, as data.

Use it in your code

  
Any web page can import the module from the live site. It works from any website.

  
<script type="module">
  import { checkMedicines } from 'https://usv240.github.io/heat-meds/src/api.js';

  const result = await checkMedicines(
    ['furosemide 40 mg', 'lisinopril', 'atorvastatin'],
    { zip: '85004' }
  );
  console.log(result.text);        // the plan as plain text
  console.log(result.plan.cards);  // one card per medicine that matters in heat
  console.log(result.unresolved);  // names a person must confirm; nothing is guessed
</script>


  
What you get back

  
    
    
  • plan.cards: each medicine the CDC lists, with why it matters, what to watch for, a pharmacist question, and the exact CDC quote, link, and check date.
    • 
    
  • plan.combinations and plan.storage: the CDC combination warning and storage notes.
    • 
    
  • plan.not_listed: medicines the CDC does not list, with what UK and Canadian guidance say.
    • 
    
  • plan.week and heat: seven days of National Weather Service HeatRisk, or why there is none.
    • 
    
  • unresolved: names that need a person to confirm. The check never guesses.
    • 
    
  • disclaimer: always present. Show it with the result.
    •

Rules for using it

  
    
    
  • Keep the disclaimer, and never present the result as an instruction to stop or change a medicine.
    • 
    
  • Send up to a couple of dozen names per call. RxNorm asks for no more than twenty requests per second per computer; the module sends a few at a time.
    • 
    
  • Keep the National Library of Medicine attribution shown below.
