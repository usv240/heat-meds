# Fonts

Atkinson Hyperlegible Next, by Braille Institute of America, from the Google Fonts repository
(https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegiblenext), licensed under the
SIL Open Font License 1.1 (see OFL.txt). Converted from the repository's variable TTF files to
WOFF2 with fontTools; no glyphs were changed.
